# GitHub Repository Tracker

## Requirements Covered

- **Part 1 – Fetch Public Repositories:** Accepts a username, fetches repositories using `fetch()`, and displays them on the webpage and in the browser console.
- **Part 2 – Fetch Owner Details:** Fetches the profile of the repository owner, displays owner details along with the repositories, and asynchronously fetches data for each repository owner.
- **Part 3 – Refresh Data Automatically:** Uses `setInterval()` to automatically refresh repository data every 60 seconds.
- **Part 4 – Error Handling:** Catches errors using `try...catch` for invalid usernames (404), network issues, and users with 0 public repositories.
- **Part 5 – Async/Await:** Implemented using modern `async`/`await` syntax with `try...catch` blocks.

---

## Project Files

- `index.html`: Very simple HTML with an input box, button, and display areas.
- `styles.css`: Minimal CSS for basic readable styling.
- `app.js`: Clean JavaScript file containing the asynchronous logic.
